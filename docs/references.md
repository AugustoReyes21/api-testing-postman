# Referencias técnicas

Consultadas para contrastar las capacidades empleadas; las verificaciones reales están en evidence/.

- OpenAPI Initiative. OpenAPI Specification 3.1.0: https://spec.openapis.org/oas/v3.1.0.html
- JSON Schema. Validating OpenAPI and JSON Schema: https://json-schema.org/blog/posts/validating-openapi-and-json-schema
- Node.js. Módulo SQLite: https://nodejs.org/api/sqlite.html (la versión ejecutada se registra en evidence/tool-versions.json).
- Postman. Importar datos: https://learning.postman.com/docs/getting-started/importing-and-exporting/importing-data/
- Postman. Reporteros de Newman: https://learning.postman.com/docs/reference/newman-cli/newman-built-in-reporters/
- Claude Code. Interfaz CLI, consultada para comprobar disponibilidad: https://code.claude.com/docs/en/cli-reference

La documentación actual de Postman advierte que Newman no ejecuta el formato v3 de Native Git. Esta práctica conserva la colección v2.1: se importó realmente en Postman 12.32.4 y se ejecutó con Newman 6.2.3. No se afirma compatibilidad de Newman con colecciones v3.
