# Matriz de pruebas

18 casos funcionales distintos, TC-01 a TC-18. La colección contiene 46 solicitudes y 234 aserciones. Las variantes de un mismo riesgo no se contabilizan como casos adicionales. SETUP y CLEANUP no añaden casos funcionales. Dependencia general: ejecutar la colección completa en orden tras preparar una base limpia. TC-15 se ejecuta después de TC-18 para no borrar el pedido antes de verificarlo.

Todas las solicitudes comprueban código, encabezados de correlación y caché; las respuestas con cuerpo comprueban Content-Type y su esquema. La validación de cuerpos en Postman es distinta de la validación documental y de intercambios HTTP descrita en el README.

La persistencia a través de un reinicio del servidor se verifica adicionalmente en `npm run verify` y se registra en `evidence/persistence-restart.json`; no se cuenta como un caso adicional de la colección.
